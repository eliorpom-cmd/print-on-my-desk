# Code of conduct

This is a small project with a narrow purpose, and it is somebody's home
printer. That second part is why this file exists rather than being assumed.

## The short version

Be decent. Assume the person on the other end is doing their best with less
context than you have.

## What is expected

* **Say what you saw.** A bug report that describes what happened beats one
  that describes what you concluded. "It printed diagonal noise" is useful;
  "your bitmap code is broken" is the same information with a worse afternoon
  attached.
* **Take a "no" without a fight.** [CONTRIBUTING](CONTRIBUTING.md) lists things
  that will be turned down, and the list is honest rather than a formality. A
  good change can still be out of scope. That is not a judgement of you.
* **Remember the paper.** This project makes a physical event happen in a room
  where somebody sleeps. Anything you propose that makes it easier to print
  unattended, faster, or without approval will be read in that light.

## What is not

Harassment, insults, or personal attacks. Sexual attention or imagery.
Publishing anybody's private information. Deliberately submitting content
designed to reach somebody's printer as abuse — including through a deployment
of this project, which is the version of it that would actually hurt somebody
here.

None of that is welcome, and none of it is a grey area.

## Scope

Issues, pull requests, discussions, and anything else in this repository's
spaces. It also covers behaviour elsewhere that is aimed at somebody because of
their involvement here.

## Reporting, and what happens

Report it privately to the maintainer — through the repository's **Security**
tab, or by email if the repository lists an address. Do not open a public issue
about somebody's conduct; it makes things worse for the person reporting more
often than it helps.

You will get a reply. What happens after that is a judgement call, made by one
person, and it ranges from a quiet word to a block. There is no committee and
no appeals process, because there is no committee — this is one person's
project, and pretending otherwise would be the kind of boilerplate this file is
deliberately not.

If the person you need to report is the maintainer, GitHub's own abuse
reporting exists and goes somewhere else entirely. Use it.
